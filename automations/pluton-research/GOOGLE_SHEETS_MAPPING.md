Use the existing Google Form response sheet. Do not rename the Form or replace it.

## Columns to add to the right of the Form responses

Add these columns exactly once. They are written by n8n; they do not modify Form questions.

| Column | Purpose |
| --- | --- |
| Pluton Submission ID | required stable Sheet-row match key; generated by a Sheet formula before n8n processes the response |
| Pluton Status | `Researching`, `Complete`, `Invalid`, or `Error` |
| Research Started | ISO timestamp |
| Research Completed | ISO timestamp |
| Primary Opportunity | top evidence-based recommendation |
| Recommended Demo | recommended Ellis demo |
| Report URL | Google Drive report link |
| Error Message | safe operational error detail |

## Required row-identity formula

The workflow only updates a row when its `Pluton Submission ID` exactly matches the triggering Form response. This prevents an accidental append or an update to the wrong prospect.

With the standard linked-Form column order shown in the fixture (`Timestamp` in A, `Business Name` in C, and `Email` in E), place this in the first data cell of the `Pluton Submission ID` column:

```gs
=ARRAYFORMULA(IF(A2:A="",,A2:A&"|"&E2:E&"|"&C2:C))
```

Do not use a static value and do not let n8n generate this key. If the Form response columns are in a different order, adjust only the three references so the formula remains `Timestamp|Email|Business Name`. Verify the formula has populated the test row before activating the workflow.
